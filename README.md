# aicode

AI learning project — personal sandbox for learning, experimenting and building with AI.

## Purpose

This repository is a workspace for:

- Learning AI/ML concepts and techniques
- Experimenting with models, prompts and agents
- Building small projects and demos
- Collecting notes, code snippets and references

## Structure

```
.
├── notes/        # Learning notes and summaries
├── experiments/  # Hands-on experiments and demos
├── projects/     # Small AI projects
└── references/   # Useful links, papers and resources
```

## Getting Started

1. Clone the repo
2. Pick a topic to explore under `notes/` or `experiments/`
3. Add your own code, notes and results

Happy learning.
